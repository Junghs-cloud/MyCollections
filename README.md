1. 메일을 이용한 회원 가입 기능
   
2. 로그인 기능
   
   -EncryptedSharedPreferences를 사용해 로그인 상태를 유지합니다.
3. 비밀번호 변경 기능
   
   -회원 가입 시 입력한 이메일로 비밀번호 변경 확인 메일을 전송해 안전성을 확보하였습니다.
  
4. 회원 탈퇴 기능

5. 구매한 상품의 추가 / 수정 / 삭제

   - 이번 달 발매하는 상품과 앨범식으로 이루어진 전체 구매 상품들을 확인할 수 있습니다.
     
   - 갤러리 앱과 연동하여 구매한 상품의 이미지를 넣을 수 있습니다.
     
   - MVVM 모델과 옵저버 패턴을 사용하여 추가 / 수정 / 삭제가 이루어질 시 이번 달 발매 상품 화면과 전체 구매 상품 화면 모두 갱신되도록 하였습니다.
